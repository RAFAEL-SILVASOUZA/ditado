# Segurança

Se encontrar uma vulnerabilidade, não publique detalhes ou credenciais em issues.

Use "Report a vulnerability" na aba Security do repositório para enviar o relato em privado.

Inclua sistema operacional, versão, impacto e passos para reproduzir.

Os instaladores ainda não possuem assinatura digital. Use somente os canais oficiais do projeto.
