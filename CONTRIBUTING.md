# Como contribuir

1. Abra uma issue para relatar problemas ou propor alterações grandes.
2. Crie uma branch para sua mudança.
3. Execute `npm ci`, `npm run typecheck`, `npm test` e `npm run build`.
4. Envie um pull request descrevendo alterações, riscos e testes.

Não inclua gravações, modelos, arquivos gerados, dados pessoais ou credenciais.

Ao alterar microfone, atalhos ou colagem, teste o comportamento nas plataformas afetadas.
